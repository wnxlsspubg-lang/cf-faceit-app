# CF FACEIT — приложения для Android и iOS

Приложение открывает сам сайт https://cf-faceit-wcfgrade.msk1.amvera.tech внутри себя,
поэтому **всё синхронизировано**: тот же аккаунт, ELO, лобби, матчи, сообщения,
уведомления — что сделал в приложении, сразу видно на сайте и наоборот.
Когда обновляешь сайт на Amvera, приложение обновляется само (пересобирать не нужно).

Что умеет: вход сохраняется, прикрепление скриншотов из галереи, кнопка «Назад»,
Telegram/менеджер/канал открываются в своих приложениях, экран «Нет соединения»,
тёмная тема #0A0507, на iOS — обновление свайпом вниз и жест «назад».

---

## Android (APK) — самый простой способ: Android Studio

1. Открой Android Studio → **Open** → выбери папку `android`.
2. Дождись, пока внизу закончится «Gradle sync» (первый раз 3–10 минут, он сам всё скачает).
3. Меню **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
4. Справа внизу появится «APK(s) generated» → **locate** → файл `app-debug.apk`.
5. Кинь его на телефон (Telegram «Избранное» тоже подойдёт) и установи
   (телефон спросит разрешить установку из неизвестных источников — разреши).

Этот APK можно раздавать игрокам — например, выложить в канал @CFFACEITOFF.

### Для Google Play (по желанию)
Нужен подписанный релиз: **Build → Generate Signed App Bundle / APK** → создай ключ
(файл .jks сохрани и не теряй — без него не выпустишь обновление) → Android App Bundle.
Аккаунт разработчика Google Play — разовый взнос $25.

## Android и iOS без своего компьютера — через GitHub (бесплатно)

1. Создай репозиторий на github.com и загрузи туда **всё содержимое этой папки**
   (вместе со скрытой папкой `.github`).
2. Вкладка **Actions** → «Build CF FACEIT apps» → **Run workflow**.
3. Через ~5–10 минут внизу страницы запуска будут файлы:
   - `CF-FACEIT-android` → внутри `CF-FACEIT.apk` (готов к установке);
   - `CF-FACEIT-ios` → `CF-FACEIT-unsigned.ipa`.

## iOS — важно знать

Apple не даёт ставить приложения просто файлом. Варианты:

- **Без затрат, сразу:** на iPhone открыть сайт в Safari → «Поделиться» →
  **«На экран «Домой»»**. Появится иконка CF FACEIT, сайт откроется на весь экран
  как приложение — данные те же.
- **Себе на iPhone бесплатно:** `CF-FACEIT-unsigned.ipa` из GitHub ставится через
  Sideloadly / AltStore со своим Apple ID (переподписывать раз в 7 дней).
- **App Store / TestFlight для всех игроков:** нужен Apple Developer ($99/год) и Mac
  (или облачный Codemagic). На Mac: `brew install xcodegen`, в папке `ios` выполнить
  `xcodegen generate`, открыть `CFFaceit.xcodeproj`, во вкладке Signing выбрать свою
  команду → Product → Archive → Distribute App.

## Если сменится адрес сайта
- Android: `android/app/build.gradle` — строка `siteUrl`, и `AndroidManifest.xml` — `android:host`.
- iOS: `ios/CFFaceit/Info.plist` — ключ `CFSiteURL`.
